# 可复用提示词模板（40 条）

> 与具体论文内容无关的操作模板。`【】` 为待填参数。优先级：`P0` 每篇必做｜`P1` 决定质量上限｜`P2` 交付前打磨。
> 用法：复制对应条目，替换参数，**末尾必须附 SKILL.md 第 2 节的通用约束块**。

## 〇、通用约束块（任何改写类任务必附）

```
【范围】只改我列出的条目/段落，其余内容逐字不动；不要顺手"优化"相邻句子。
【禁区】不改数据与结论；不删技术规格、判据、阈值；不动图表、公式、引注编号；不新增未核验文献。
【产出】①改动清单表（编号｜位置｜原文摘要｜改后｜依据）②核验报告：段落/表/图/公式/引文计数前后对比、关键数字集合前后比对、全文 diff 是否仅含计划改动 ③待确认项。
【纪律】无法核实的写【待核实】并列出，禁止编造；口径有多种可能时先列选项问我，不要默认选一种。
【判据】凡"润色/精简/优化"，先说明你的判定标准，再逐条对照执行。
```

## 一、基线与版本管理（贯穿全程）

| 编号 | 条目 | 优先级 | 时点 |
|---|---|---|---|
| G1 | 版本链与备份命名 | P0 | 每次动手前 |
| G2 | 改动说明文档 | P0 | 每次交付 |
| G3 | 程序化核验与 diff 自证 | P0 | 每次改完 |

### G1｜版本链与备份命名 `P0`
> 修改前把当前文件复制为 `_V【n】_【本次主题】前备份.docx`；产出另存为 `V【n+1】_【主题】.docx`，原文件一律不动。最后告诉我本次的版本链（从哪版到哪版、改了什么）。
- 效果：任何一步出错都能回退。文件被 Word 占用时先另存，不覆盖正在编辑的实例。

### G2｜改动说明文档 `P0`
> 另出一份《【阶段】修改说明.md》，逐条给：意见/问题编号 → 命中位置（章节或段落号）→ 原文摘录 → 改后 → 判定依据（规范条款/原文自洽/文献核验）。文末列"未落实项及原因"和"需作者确认项"。

### G3｜程序化核验与 diff 自证 `P0`
> 改完做独立核验，报告：①段落/表格/图片/公式/引文总数前后对比 ②关键数字多重集合前后比对（列出差异并逐条解释）③全文逐段 diff，确认差异只出现在计划改动的位置 ④占位符残留检查（`REPLACE_ME`、`【待…】`、`[]`、乱码、LaTeX 残片）。
- 可执行 `scripts/verify_docx.py 旧.docx 新.docx` 自动完成 ①—④。

## 二、诊断与评审（先找问题，别急着改）

| 编号 | 条目 | 优先级 |
|---|---|---|
| R1 | 多身份量化评审 | P0 |
| R2 | 数据自洽复算 | P0 |
| R3 | 指标一致性索引审计 | P0 |
| R4 | 承诺—兑现审计 | P1 |
| R5 | 文献真实性核验 | P0 |
| R6 | 外部意见逐条裁定 | P1 |

### R1｜多身份量化评审 `P0`
> 以【学科教授 + 期刊审稿人】双重身份评审 `【文件】`。输出：①量化评分（百分制）与结论等级（通过/小修/大修/不通过）②问题按 A 致命（推翻结论）/B 重大（影响可信度）/C 一般/D 编辑性四类分列，每条给位置、原文、问题、可执行的改法 ③"答辩必被问"清单 ④修改顺序建议。
> 不要泛泛评价，每一条必须能定位到具体段落或数据。
- 变体：需要更强火力时用"多方评审团"（方法学/领域专家/统计/编辑/答辩委员各一人，独立打分后汇总分歧）。

### R2｜数据自洽复算 `P0`
> 用论文自己给出的参数和公式，逐项复算它宣称的结果：把每个关键结论（降幅、效益、指数、评分）还原成算式，检查 ①量纲/单位是否一致 ②分子分母口径是否同一 ③算术是否成立 ④反算得到的中间值是否与正文其他处一致。列出算不通的项，给出"要么改数、要么改表述"两条路径。
- 效果：最快抓出推翻结论级硬伤（量纲错、口径混用、目标值精确命中之类）。通读十遍也未必发现，代入算一次就露。

### R3｜指标一致性索引审计 `P0`
> 按"指标"建索引：对每个关键指标抓出全文所有出现处，列成表（位置｜数值｜口径｜表述），标出互相矛盾的组合；同时检查同一概念是否存在两套定义/两套维度。

### R4｜承诺—兑现审计 `P1`
> 提取摘要、引言、结论中所有"提出/构建/建立/填补空白"类承诺，逐条到正文找落点（具体小节、定义、公式、表、验证）。输出三列：承诺原句｜正文落点｜状态（已兑现/仅提及/无落点）。无落点的，给"补写 200–400 字"或"降级表述"两个方案。

### R5｜文献真实性核验 `P0`
> 逐条核验参考文献：作者、题名、刊名、年、卷(期)、页码、DOI。核验优先级：期刊官网目录/PDF 内的引用格式 > 国家知识仓储 > 第三方题录站。输出表：编号｜原文著录｜核验结果（正确/著录错误/查无此文）｜正确著录｜依据链接。查不到的标记"疑似虚构"，不要擅自替换成相似文献。
- 这是学术底线问题，必须前置做。

### R6｜外部意见逐条裁定 `P1`
> 对以下【N】条意见逐条裁定，用三重判据（技术合理性 × 可行性 × 对核心贡献的边际价值）：采纳 / 修改后采纳（写明改法）/ 不采纳（写明理由与替代方案）。最后给"执行顺序表"（先数据审计 → 再结论表述 → 再理论 → 再结构 → 最后文献格式），并标出互相冲突的意见。

## 三、结构与论证

| 编号 | 条目 | 优先级 |
|---|---|---|
| S1 | 研究问题体系贯通 | P0 |
| S2 | 综述"共识—矛盾—缺口—切入" | P1 |
| S3 | 结论—证据映射表 | P1 |
| S4 | 竞争性解释与限定 | P1 |
| S5 | 章节导引去元话语 | P1 |
| S6 | 结构重构方案 | P1 |

### S1｜研究问题体系贯通 `P0`
> 建一套研究问题体系：1 个核心问题 → 3 个子问题（MECE）→ 1 句核心论点 → 研究边界（不做什么）。然后检查全文贯通：摘要、每章章首、每章小结、结论是否都回扣到问题体系；不一致的给出改写句。

### S2｜综述"共识—矛盾—缺口—切入" `P1`
> 把【X.X 节】综述改写为四段式：①本领域已形成的共识（谁在什么层面一致）②现有研究的矛盾/分歧（对立结论及各自证据）③缺口（方法/对象/情境/数据哪一类没被覆盖）④本文切入（承接哪个缺口，用什么不同做法）。删除纯罗列句，保留有对话关系的文献。只允许重组，不允许新增事实。

### S3｜结论—证据映射表 `P1`
> 做一张"结论—证据"映射表：结论条目｜支撑证据（表/图/检验/案例）｜证据强度（强/中/弱）｜限定条件。凡"弱"的结论，改写为有限定语的表述；凡找不到证据的结论，删除或降为"讨论"。

### S4｜竞争性解释与限定 `P1`
> 为【核心结论】列 3–5 个竞争性解释（同期其他举措、数据少报、回归均值、样本变化等），逐个用已有证据辩驳或承认无法排除；随后写一段 Qualifier（本结论在什么条件下成立、不外推到什么范围）。

### S5｜章节导引去元话语 `P1`
> 改写全文【N】处章节导引，去掉"本章回答/按…顺序展开/第 n 节讲…"这类自我解释性元话语，改为内容主导的叙述（直接讲本章要解决的实际问题与判断依据）。逐段给新旧对照。刻意设计的前后照应句保留。

### S6｜结构重构方案 `P1`
> 给出结构重构方案（不直接动稿）：①问题诊断（哪章冗余/错位/权重不当）②调整后完整目录（到三级）③每处调整的"内容分流去向表"（原位置 → 新位置 / 删除 / 移附录）④连带影响清单（章节号、图表号、公式号、交叉引用、目录、页眉）⑤风险与工作量。我确认后再执行。

## 四、内容与数据

| 编号 | 条目 | 优先级 |
|---|---|---|
| D1 | 统一口径并重算下游 | P0 |
| D2 | 时间窗/统计区间澄清 | P0 |
| D3 | 补统计检验与效应量 | P1 |
| D4 | 补写而非删减 | P1 |
| D5 | 删离题内容（防孤儿化） | P1 |

### D1｜统一口径并重算下游 `P0`
> 对【指标】先定唯一口径（说明为什么选它、与哪些表述冲突），然后全文替换为唯一值，并按新口径重算所有下游数字（降幅、效益、评分、达成度），列出"改前 → 改后"对照表；口径变更波及的每一处都要交代。

### D2｜时间窗/统计区间澄清 `P0`
> 核对所有时间区间表述：把"实施期 / 数据统计期 / 观察期 / 对比基期"分别列出起止与用途，检查每个数字是否用对了分母。若原数字在某个口径下完全自洽，只做澄清与误写更正，不改编数字；若都不自洽，给出重算方案与波及范围。

### D3｜补统计检验与效应量 `P1`
> 为【核心效果】补：率比/风险比 + 95% 置信区间 + 检验方法与 p 值 + 效应量，并给一句"现实意义换算"（相当于全年减少多少起/每多少工时避免一起）。样本不足时如实说明不显著，不报虚假精度；同时说明该检验的前提假设与局限。

### D4｜补写而非删减 `P1`
> 为【概念/框架】补写落地内容：操作化定义（可观测判据）+ 计算或评定规则（阈值/权重/分级）+ 用论文已有数据试算一例。控制篇幅【N】字内，不新增未核验文献，不改动既有编号体系（如需新增编号，先告知连带影响）。

### D5｜删离题内容（防孤儿化）`P1`
> 候选删除清单：给出每段的位置、摘要、删除理由（离题/重复/低信息量）。删除前对每段的关键词做全文检索（含"见 X.X 节"式间接引用），确认无交叉引用与逻辑前件；有引用的先给"移入附录/压缩为一段"的替代方案。我确认后再删。

## 五、文献与引注体系

| 编号 | 条目 | 优先级 |
|---|---|---|
| L1 | 按首引顺序重排 + 区间展开 | P0 |
| L2 | 引文上标 + 内部超链接 + 书签 | P1 |
| L3 | 文献层次优化 | P1 |

### L1｜按首引顺序重排 `P0`
> 按"首次引用顺序"重排参考文献编号：①按文档顺序遍历到"参考文献"标题为止，记录首现顺序 ②校验是否为 1..N 的排列 ③逐处替换正文标注（含表格内），区间引用 [a-b] 必须先展开为逐个编号再映射，输出时若新号连续才写回区间，否则写逗号分隔 ④重排条目本身并改行首编号 ⑤输出新旧对照表。
> 识别"引用型方括号"的判据：内层完全匹配 `^\d+([,\-–]\s*\d+)*$` 且所有数字落在 1..文献数——以此排除 `[0,1]`、`[0.912,0.941]`、`[Q1−1.5IQR,…]` 等数学区间。

### L2｜引文上标 + 超链接 + 书签 `P1`
> 把正文【N】处引用标注改为：保留方括号、整体上标（`vertAlign=superscript`）、外层包内部锚点超链接指向 `ref_n`，目标条目首插入同名书签。不加超链接字符样式（保持正文同色无下划线）。
> 注意：①上标要按"引用徽标完整字符集"处理（`[`、`]`、数字、`-`、`,` 全部上标），不能只处理数字 ②复制模板 run 的格式时，模板自带的 `vertAlign` 会静默污染结果 ③`rPr` 子元素有 schema 固定顺序。

### L3｜文献层次优化 `P1`
> 审查文献结构：按"核心期刊/权威标准/学位论文/普刊/网络来源"分层统计；标出低层次、低相关、仅凑数的条目；给出"删【N】条 + 补【M】条"的方案，补充条目必须逐条核验可查并注明与本研究的对话关系。新增条目单独编号，不打乱既有编号。

## 六、语言表达

| 编号 | 条目 | 优先级 |
|---|---|---|
| W1 | 全文去 AI 味（学术语体） | P1 |
| W2 | 定点润色（不动事实） | P1 |
| W3 | 标点与符号规范 | P2 |
| W4 | 术语一致性 | P2 |

### W1｜全文去 AI 味（学术语体）`P1`
> 按学术语体去 AI 味：保留被动客观语体、专业术语、全部数据与判据；不引入第一人称与口语。
> 清理对象：空话连接词（"需要说明的是/总体来看/由此可见/此外"）、机械排序（"首先…随后…最后"）、同构小标题模板（同一结构重复 5 次以上）、口号式收尾（"闭环就此形成"）、自我评价式收尾（"体现了…的约束力"）、无主语的"机制揭示"、名词化长主语、三段式排比开头、"被"字双重被动、冗余同义反复。
> 保留：术语名、真实对比的"不是…而是"、核心论点的三联句。
> 硬约束：只删套话，不动技术规格、阈值、判据、数字。输出前后数字集合比对与"过度删减"报警（新段长度 < 原文 60% 需复核）。
- 验收可量化：套话词频清零、同构模板计数下降、前后数字集合一致。

### W2｜定点润色（不动事实）`P1`
> 只改我列出的【N】处（给编号+原文片段）。每处改前改后都要能对上：`改后文本 == 原文.replace(旧, 新, 1)`。改写不跨越引文标注 `[n]`。改完逐条列出对照，并声明"未改动段落数 = 总段数 − N"。

### W3｜标点与符号规范 `P2`
> 统一以下四类，先出规则再动手：①冒号——只能有一个提示层级，禁止跨层嵌套（"一句双冒号"要拆），标题不用"主题：副题"式 ②连接符——表示起止用 `–`，图表号/公式号/文献区间用半角 `-`，国家标准号年号用 `—`，减号 `−` 不参与统一 ③数值与单位——数字与符号间 1 个空格，`%` 不留空格，同一物理量只用一种形式（有符号就不用汉字）④引号/正斜体/上下标。
> 每条给出"改动数 + 分布"，并列出"看起来像但要保护"的反例（算式、区间、公式号）。

### W4｜术语一致性 `P2`
> 建立术语表（概念｜首选表述｜禁用别名｜首次定义位置）。全文检查：同一概念是否只用一种表述、缩略语是否只在首次出现处展开、图表题注与正文用词是否一致。输出替换清单，专有名词与已定型的维度名保留原样。

## 七、格式体例

| 编号 | 条目 | 优先级 |
|---|---|---|
| F1 | 按"规范+官方模板"全套统一 | P0 |
| F2 | 标题层级与样式校正 | P1 |
| F3 | 三线表重建 | P1 |
| F4 | 题注与图表清单 | P1 |
| F5 | 页眉页脚/分节页码/目录域 | P1 |

### F1｜全套格式统一（只排版、不动正文）`P0`
> 依据《【学校】研究生学位论文写作规范》+ 官方模板 docx，只做排版不改正文：页边距、页眉页脚距、Normal 与 Heading1–4 样式、章标题编号体例、正文对齐/首行缩进/行距、摘要与关键词、图表题注、参考文献、分节与页码、目录域。
> 交付时给"逐项对照表（规范条款 → 落实值）"和去空白全文 diff，证明正文语句零改动。

### F2｜标题层级与样式校正 `P1`
> 按"章—节—条"校正层级：`X` → Heading1，`X.Y` → Heading2，`X.Y.Z` → Heading3，`X.Y.Z.W` → Heading4；正文误用标题样式的改回正文；清理残留的直接格式（outlineLvl/加粗/字号），改为样式驱动。
> 注意区分"自定义样式"与内置 Heading，检查前先做 styleId → name 映射，判断某标题是否进目录要看段落级 outlineLvl。

### F3｜三线表重建 `P1`
> 全部数据表统一为三线表：顶线/底线 1.5 磅、栏目线 0.75 磅、无竖线与内部横线；表头加粗；表内五号，中文宋体+西文 TNR；单元格水平垂直居中、取消首行缩进、单倍行距；表宽归一到版心宽（按原比例缩放）；表格整体居中、固定布局。
> 校验要按单元格级边框判定（表级属性可能被覆盖），`None` 边框必须写 `w:val="nil"`，改完逐表复核。

### F4｜题注与图表清单 `P1`
> 题注规范：表题在上、图题在下，五号居中，段前段后 6 磅，中英文对照（英文另起一行）；正文必须有"见图 X-X / 见表 X-X"的引用，且编号存在。
> 同步维护"图表清单"：条数 = 正文图表数、编号顺序与正文一致、每条带页码。改题注必须同步改清单，否则必然不一致。题注判定正则必须要求"编号后有空白"，否则误伤正文引导句。

### F5｜页眉页脚/分节/页码/目录 `P1`
> 分节：封面区无页眉页码；前置部分（摘要/目录）用大写罗马数字；正文第 1 章起阿拉伯数字从 1 重排。页眉统一校名/论文类型，右页（或奇数页）用 STYLEREF 引用章标题。目录用自动 TOC 域，只收三级标题，正文改完提示"在 Word 中全选 F9 更新域"。

## 八、图表与公式

| 编号 | 条目 | 优先级 |
|---|---|---|
| T1 | 插图体检 + 图源溯源 | P1 |
| T2 | 按插入尺寸出图 + 程序化排版校验 | P1 |
| T3 | 就地换图 / 矢量化 / 高清化 | P2 |
| T4 | 公式规范化 | P2 |

### T1｜插图体检 + 图源溯源 `P1`
> 逐图体检并出表：图号｜像素尺寸｜插入物理尺寸｜图内文字实际打印字号（= 源字号 × 插入宽 ÷ 源图物理宽）｜是否与正文/题注一致｜是否有旧图号残留｜留白与边框是否压线。
> 需要判断"这张图是哪来的、有没有过期"时，把历史绘图脚本重新渲染，与文档内嵌图做灰度归一化相关比对（先统一宽高比，再做竖向滑动搜索裁切偏移）。

### T2｜按插入尺寸出图 + 程序化校验 `P1`
> 按论文实际插入宽度出图：`figsize` 直接取插入宽度（如 15.5 cm → 6.10 in），`add_axes([0,0,1,1])` + `set_aspect('equal')`，使 1 单位两向等长、脚本字号即打印字号。字体用系统可用中文字体。
> 出图后程序化校验（不要靠肉眼）：用 `Text.get_window_extent()` 反算数据坐标，逐个比对"文字包围盒 vs 所属图形框"查溢出、两两比对查重叠、比对坐标范围查越界；迭代到 0 溢出 / 0 重叠 / 0 越界。
> 图内不要写"图 X-Y"，编号由题注承载。

### T3｜就地换图 / 矢量化 / 高清化 `P2`
> 在文档内就地替换图片：定位图题段 → 取图片关系 → 替换图像字节 → 同步修改 `wp:extent` 与 `a:ext` 的宽高（两处都要改，否则变形），保持显示尺寸不变。要求在替换前后给出"页数/图数/版面零位移"的核验。
> 矢量化时：用成熟库（不要自写轮廓算法），`filter_speckle` 是保形关键（过大会把细线小字当噪点抹掉）；评估与出图必须用同一个渲染器；保真度用"多边形面积 vs 掩膜面积逐层比对 + 打印尺度下的 SSIM + 着墨偏差"，不要用降采样 IoU 或低分辨率相关。
> 注意：Word 导出 PDF 时默认把高于约 220 ppi 的图压到 220 ppi，要保真需在 Word 选项里勾"不压缩文件中的图像"。

### T4｜公式规范化 `P2`
> 按章给公式编号 `(章-序)`；版式用"居中制表位 + 右顶格制表位"（版心 1/2 与版心宽），内容为 `TAB + 公式 + TAB + 编号`；公式宽超过版心一半时拆行（次行用两个 TAB 跳过居中位）；清理 LaTeX 残片与行内多余符号；正文若有"式(X-Y)"引用，编号变更需同步。章节归属必须用章标题样式判定，不能用"往前找第X章"文本匹配。

### P1｜定量精简 `P1`

## 十一、推荐执行顺序（一条主线）

```
G1 备份 → R1 评审 → R2 复算 → R3 一致性 → R5 文献核验
   ↓

   ↓

   ↓

   ↓

   ↓
```

## 附：三条可直接复制的组合提示词

**① 全面诊断（新稿第一轮）**
> 以【学科教授 + 期刊审稿人】身份评审 `【文件】`。先做四项程序化核验：关键数字跨章一致性、公式与结论复算、摘要承诺在正文的落点、参考文献真实性（逐条给核验依据）。再按 A/B/C/D 分类出问题清单（位置+原文+问题+改法），给百分制评分与结论等级，最后列"答辩必被问"与"修改顺序"。不要泛评。

**② 定点修改（意见落实）**
> 按《【意见清单】》逐条落实，只改对应位置。先给我"落实方案表"（意见 → 拟改位置 → 改法 → 是否牵动编号/数据），我确认后再动手。改完给：改动清单、核验报告（结构计数、关键数字集合、diff 范围）、未落实项与理由。无法核实的标【待核实】，不得编造。

**③ 格式整理（内容定型后）**
> 依据《【规范】》+ 官方模板，只做排版不动正文。逐项落实并在报告里给"规范条款 → 落实值"对照；交付时附去空白全文 diff，证明除版式项外正文零改动，并列出图表数/段落数/关键数字守恒情况。
